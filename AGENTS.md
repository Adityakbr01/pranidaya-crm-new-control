# Agent Instructions & Design Standards

## UI Redesign & Frontend Rules
When requested to redesign, build, or polish any user interface:
- **Always Apply `testskill` & `impeccable`**:
  - Apply `testskill` (`.agents/skills/testskill` / `design-taste-frontend`) anti-slop rules, strict typography, and deliberate layout hierarchy.
  - Apply `impeccable` (`.agents/skills/impeccable`) design guidance, craft floor standards, and UX review checks.
  - Reject generic AI templates (bland purple mesh gradients, untinted grays, generic nested cards).
  - Deliver production-grade, highly polished, responsive components with thoughtful micro-interactions.
