# Frontend Redesign & UI Guidelines

Whenever the user asks to redesign, beautify, style, or enhance any frontend UI, pages, or components:
1. **Always Use `testskill` / `design-taste-frontend`**:
   - Infer the design direction and set the core variance/motion/density dials.
   - Ban generic AI defaults (purple-to-blue gradients on dark mesh, plain un-tinted grays, nested cards).
   - Use high-contrast typography, calibrated color palettes, and deliberate whitespace.
2. **Always Use `impeccable`**:
   - Adhere to the craft floor and design guidance for production-grade UI.
   - Enforce distinct, beautiful, and inspiring visual craft.
   - Handle UX review, visual hierarchy, purposeful motion, responsive behavior, and clean accessible forms.
